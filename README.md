# RUSlangIDE

> Учебная среда разработки для работы с программами на русском языке.

RUSlangIDE — Windows-приложение, созданное по образцу **Semantic IDE**. Оно позволяет изучать основы алгоритмов и программирования в знакомой русскоязычной нотации, запускать программы, разбирать их структуру и получать код для распространённых языков программирования.

[⬇️ Скачать последнюю версию](https://github.com/kartoxa8/ruslang-ide/releases/latest)

> Проект не связан с авторами Semantic IDE и не является её официальным релизом. Наименование Semantic IDE упоминается только для указания источника вдохновения и совместимого подхода.

## Возможности

- создание и редактирование программ в формате `.sl`;
- запуск и семантический анализ программ локально;
- работа с функциями, процедурами, условиями, циклами, массивами, указателями и классами;
- набор готовых учебных примеров: «Hello, мир!», факториал, сортировка пузырьком, рекурсия, строки, файлы, классы и другие;
- преобразование программ в **C++**, **Go** и **Python**;
- автономная работа: среда исполнения Java включена в дистрибутив.

## Быстрый старт

1. Откройте раздел [Releases](https://github.com/kartoxa8/ruslang-ide/releases/latest) и скачайте архив последней версии.
2. Распакуйте архив целиком в любую папку.
3. На Windows запустите `RUSlangIDE.exe` из распакованной папки.

Дополнительная установка Java, Node.js или компилятора для запуска самой IDE не требуется.

Не перемещайте `RUSlangIDE.exe` отдельно: для работы ему нужны папки `resources`, `locales` и файлы библиотек из архива.

## Пример

Встроенный пример `HelloWorld.sl` выводит в консоль:

```text
Привет, Мир!
```

Файлы `.sl` хранят программу в XML-представлении: их удобно открывать в среде, передавать и добавлять к учебным заданиям.

## Состав архива дистрибутива

| Компонент | Назначение |
| --- | --- |
| `RUSlangIDE.exe` | Основное приложение для Windows x64 |
| `resources/app.asar` | Пользовательский интерфейс Electron |
| `resources/backend/ksemantic-api.jar` | Локальный API, анализатор и исполнитель программ |
| `resources/backend/jre` | Встроенная Java Runtime Environment 21 |
| `resources/convertor` | Конвертер исходного кода в C++, Go и Python |
| `resources/samples-data` | Коллекция учебных программ `.sl` |

## Технологии

- **Electron** — настольный пользовательский интерфейс;
- **Kotlin + Spring Boot** — локальный backend и API;
- **Java 21** — исполнение backend-части;
- **C++, Go и Python** — целевые языки конвертера.
